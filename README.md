# Pet_Project_film_catalog
Некоммерческий пет-проект каталог фильмов. Приложение показывает актуальную информацию о фильмах, 
включая постеры, название, рейтинг и год выхода. 
Возможность перемещения по страницам, от 1 до 10, путем выбора нужной страницы внизу экрана.

## Как запустить
1. Клонируйте репозиторий. После клонирования откройте проект в AStudio и дождитесь синхрониазции Gradle. 
2. Установите зависимости и добавьте API poiskkino в файл local.properties (лежит в корне проекта):`TMDB_API_KEY=YOUR_API_KEY`. 
3. Подключите устройство или эмулятор на ОС Android к компьютеру
4. Запустите проект при помощи треугльной кнопки "Run" (Shift + F10) в Android Studio.
5. Наслаждайтесь просмотром фильмов. 

## Ограничение демо-тарифа API key
Во время проверки API вернул 109631 в поле pages — это общее число страниц каталога. 
Приложение использует pages как верхнюю границу нумерации, поэтому в ряду может появиться кнопка «11».
На демо-тарифе доступны страницы 1–10, а при запросе страницы 11 и выше сервер возвращает HTTP 403 Forbidden.
